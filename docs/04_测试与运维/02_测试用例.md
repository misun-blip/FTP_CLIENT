# 测试用例

## 1. 功能测试

| 编号 | 测试项 | 输入 | 预期结果 |
|---|---|---|---|
| F-01 | 建立连接 | 正确主机和端口 | 连接成功 |
| F-02 | 登录成功 | 正确用户名密码 | 登录成功 |
| F-03 | 登录失败 | 错误密码 | 提示认证失败 |
| F-04 | 目录浏览 | 远程目录路径 | 正确显示文件列表 |
| F-05 | 文件下载 | 指定远程文件 | 本地生成完整文件 |
| F-06 | 文件上传 | 指定本地文件 | 远程出现对应文件 |
| F-07 | 下载续传 | 中断后重新下载 | 从断点继续 |
| F-08 | 上传续传 | 中断后重新上传 | 从断点继续 |
| F-09 | 日志展示 | 任意操作 | 正确显示命令与响应 |
| F-10 | 进度展示 | 传输任务 | 正确显示进度 |

## 2. 异常测试

| 编号 | 场景 | 预期结果 |
|---|---|---|
| E-01 | 服务器地址错误 | 连接失败并提示 |
| E-02 | 服务器断开 | 任务终止并记录日志 |
| E-03 | 文件不存在 | 提示文件不存在 |
| E-04 | 本地文件被占用 | 上传失败并提示 |
| E-05 | 磁盘空间不足 | 下载停止并提示 |
| E-06 | 网络中断 | 可重新发起续传 |

## 3. 公共支撑测试

| 编号 | 测试项 | 输入 | 预期结果 |
|---|---|---|---|
| Q-01 | 日志信息输出 | 调用 `info("ready")` | 输出 INFO 级别日志 |
| Q-02 | 日志错误输出 | 调用 `error("failed")` | 输出 ERROR 级别日志 |
| Q-03 | 日志文件写入 | 配置日志文件路径并写入日志 | 文件生成且包含日志内容 |
| Q-04 | 配置默认加载 | 配置文件不存在 | 返回默认配置，不报错 |
| Q-05 | 配置保存读取 | 保存主机、端口、超时等配置后重新加载 | 加载内容与保存内容一致 |
| Q-06 | 配置非法端口 | 端口为 `70000` | 抛出配置异常 |
| Q-07 | 配置非法超时 | 超时为 `0` | 抛出配置异常 |
| Q-08 | 异常分类 | 导入项目异常类型 | 可区分连接、协议、认证、传输、配置和校验异常 |
