# 缺陷记录

## 1. 记录规则

每个缺陷至少记录：

- 缺陷编号
- 发现阶段
- 现象描述
- 影响范围
- 责任人
- 状态
- 修复说明
- 复测结果

状态取值：

```text
open
in_progress
fixed
reopened
closed
```

## 3. 复测要求

缺陷关闭前必须满足：

1. 有对应代码或文档修复记录
2. 有复测命令或测试用例证明
3. 状态从 `fixed` 变更为 `closed` 前需经过验收确认
