# 运行维护

## 1. 启动步骤

1. 安装 Python 环境
2. 安装项目依赖
3. 启动 FTP 测试服务器
4. 运行主程序

## 2. 常见问题

| 问题 | 排查方向 |
|---|---|
| 无法连接 | 检查 IP、端口、防火墙、服务器状态 |
| 登录失败 | 检查账号密码 |
| 目录为空 | 检查权限或路径 |
| 传输失败 | 检查数据连接、文件权限、服务器支持 |
| 续传失败 | 检查服务器是否支持相关命令 |

## 3. 日志维护

日志建议至少记录：

- 时间
- 操作类型
- 命令
- 响应码
- 错误信息

当前公共日志模块位于 `ftp_client/utils/logger.py`，其他模块可直接调用：

```python
from ftp_client.utils.logger import error, info

info("连接成功")
error("传输失败")
```

如需模块级 logger 或文件日志，可使用 `get_logger(name, log_file=...)`。

## 4. 配置维护

建议独立保存：

- 最近连接记录
- 默认下载路径
- 超时时间
- 日志级别

当前配置模块位于 `ftp_client/utils/config.py`，使用 JSON 文件保存。配置字段包括：

| 字段 | 说明 |
|---|---|
| `host` | 默认 FTP 主机 |
| `port` | 默认 FTP 端口 |
| `timeout` | 默认连接超时时间 |
| `username` | 默认用户名 |
| `default_download_dir` | 默认下载目录 |
| `log_level` | 日志级别 |
| `recent_connections` | 最近连接记录 |
