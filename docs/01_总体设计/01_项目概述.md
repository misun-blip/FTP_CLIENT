# 项目概述

## 1. 项目名称

基于 Socket 的 Windows 图形化 FTP 客户端

## 2. 项目背景

本项目依据课程实践要求，使用原生 `socket` 进行网络编程，实现 FTP 协议的主要功能。系统运行于 Windows 平台，并提供图形化界面，以支持文件上传、下载和断点续传等操作。

## 3. 项目目标

1. 实现 FTP 服务器连接与用户认证
2. 实现远程目录浏览与本地文件浏览
3. 实现文件上传和下载
4. 实现断点续传
5. 提供传输进度与操作日志展示
6. 保证系统结构清晰，便于多人协作与后续维护

## 4. 预期成果

1. 可运行的图形化 FTP 客户端
2. 完整项目源代码
3. 系统设计文档
4. 测试记录
5. 实验报告所需素材
