# 总体架构

## 1. 技术选型

| 类别 | 方案 |
|---|---|
| 开发语言 | Python |
| 图形界面 | PySide6 |
| 网络通信 | 原生 `socket` |
| 配置存储 | JSON 或 SQLite |
| 运行平台 | Windows |
| 版本管理 | Git |

## 2. 系统架构

```text
┌──────────────────────┐
│      用户界面层       │
│ 登录、目录、任务、日志 │
└──────────┬───────────┘
           │
┌──────────▼───────────┐
│      业务控制层       │
│ 会话、任务、状态管理   │
└──────────┬───────────┘
           │
┌──────────▼───────────┐
│      FTP 协议层       │
│ 命令封装、响应解析     │
└──────────┬───────────┘
           │
┌──────────▼───────────┐
│     Socket 通信层     │
│ 控制连接、数据连接     │
└──────────────────────┘
```

## 3. 运行流程

```text
启动程序
  ↓
输入服务器信息
  ↓
建立 TCP 控制连接
  ↓
执行 USER / PASS 登录
  ↓
获取远程目录
  ↓
执行上传 / 下载任务
  ↓
展示进度、日志与结果
```
