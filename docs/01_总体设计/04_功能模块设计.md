# 功能模块设计

| 模块 | 主要职责 |
|---|---|
| 用户界面模块 | 展示界面、响应用户操作、显示状态 |
| 连接与认证模块 | 创建 socket、建立控制连接、完成登录 |
| FTP 协议模块 | 封装命令、解析响应、维护协议流程 |
| 文件浏览模块 | 获取并展示远程目录、本地目录 |
| 上传模块 | 完成文件上传、上传续传、进度统计 |
| 下载模块 | 完成文件下载、下载续传、进度统计 |
| 日志与异常模块 | 记录命令、响应和异常信息 |
| 配置模块 | 保存服务器信息和界面配置 |

## 关键技术方案

### 1. 控制连接与数据连接

FTP 使用控制连接传递命令和响应，使用数据连接完成文件列表和文件内容传输。系统需要分别维护控制连接与数据连接，并在文件传输前建立对应的数据通道。

### 2. 断点续传

- 下载续传：通过 `REST + RETR`
- 上传续传：采用 `REST + STOR` 或 `APPE`

### 3. 图形界面异步处理

网络传输任务与 GUI 主线程分离，避免界面卡顿。
