# 需求分析

## 1. 功能需求

### 1.1 必做功能

- 服务器连接
- 用户登录
- 远程目录浏览
- 本地文件浏览
- 文件上传
- 文件下载
- 断点续传
- 图形化界面
- 日志显示
- 基本异常提示

### 1.2 扩展功能

- 删除远程文件
- 新建远程目录
- 传输队列
- 暂停、继续、取消
- 历史连接记录
- 多任务传输

## 2. 非功能需求

1. 稳定性：能够完成连续演示
2. 可维护性：模块划分清晰，接口明确
3. 易用性：界面结构清楚，操作直观
4. 可测试性：主要模块可独立验证
5. 可追踪性：关键操作具备日志记录

## 3. 约束条件

1. 客户端操作系统为 Windows
2. 协议功能必须基于原生 `socket` 实现
3. 不直接使用现成 FTP 客户端库
4. 需要明确区分各成员完成的源代码
