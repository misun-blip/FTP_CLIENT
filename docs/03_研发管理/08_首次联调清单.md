# 首次联调清单

## 1. 联调目标

首次联调只验证最短闭环，不追求功能完整。

目标：

1. 程序可启动
2. 协议层可被应用层接入
3. 能完成连接和登录
4. 能获取远程目录
5. 日志链路可用

## 2. 联调前提

| 模块 | 负责人 | 联调前必须具备 |
|---|---|---|
| 应用装配层 | 成员 1 | `main.py`、`create_app()`、公共模型 |
| 协议层 | 成员 2 | `connect()`、`login()`、`list_dir()` |
| 日志模块 | 成员 6 | `info()`、`error()` |
| GUI 骨架 | 成员 5 | 可启动窗口，或提供 mock 展示 |

## 3. 联调步骤

1. 从应用入口启动程序
2. 注入协议层实现
3. 调用 `connect()`
4. 调用 `login()`
5. 调用 `list_dir()`
6. 将目录结果输出到日志或 GUI
7. 记录异常和已知问题

## 4. 验收标准

- [ ] 主程序可运行
- [ ] 协议层对象可被成功注入
- [ ] 登录流程可完成
- [ ] 远程目录可返回 `RemoteFile` 列表
- [ ] 关键日志可输出
- [ ] 若失败，能明确知道失败发生在哪一层

## 5. 不纳入首次联调的内容

- 上传
- 下载
- 断点续传
- 完整 GUI 交互
- 大量异常场景
