# 成员 5 接入指南

## 1. 目标

成员 5 负责实现图形界面，使用户能够通过窗口完成连接、目录浏览和传输操作。

## 2. 需要实现的入口

```python
show() -> None
```

## 3. 推荐文件位置

```text
ftp_client/ui/
├─ main_window.py
└─ dialogs.py
```

## 4. 依赖

成员 5 依赖：

1. 成员 1 提供的公共模型
2. 成员 2 提供的连接与目录接口
3. 成员 3、4 提供的传输接口
4. 成员 6 提供的日志能力

## 5. 可先独立完成的部分

在真实接口未完成前，可以先使用 mock 数据完成：

1. 主窗口布局
2. 连接信息区
3. 本地目录区
4. 远程目录区
5. 任务列表区
6. 日志区

## 6. 完成标准

1. 主窗口可运行
2. 能展示远程文件和传输任务
3. 能触发连接、上传、下载操作
4. 界面操作过程中不卡死
