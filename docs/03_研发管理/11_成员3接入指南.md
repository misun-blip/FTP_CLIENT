# 成员 3 接入指南

## 1. 目标

成员 3 负责实现下载模块，使系统能够完成普通下载和下载断点续传。

## 2. 需要实现的接口

```python
download(remote_path: str, local_path: str) -> TransferTask
resume_download(remote_path: str, local_path: str) -> TransferTask
```

## 3. 推荐文件位置

```text
ftp_client/transfer/
├─ downloader.py
└─ download_resume.py
```

## 4. 依赖

成员 3 依赖：

1. 成员 2 提供的数据连接与协议命令能力
2. 成员 1 提供的 `TransferTask`
3. 成员 6 提供的日志能力

## 5. 可先独立完成的部分

在真实协议层未完成前，可以先完成：

1. 下载任务类结构
2. 本地文件写入逻辑
3. 进度更新逻辑
4. 断点大小计算逻辑

## 6. 完成标准

1. 普通下载可用
2. 下载中断后可从断点恢复
3. 返回统一 `TransferTask`
4. 能通过下载功能测试
