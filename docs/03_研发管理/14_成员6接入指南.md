# 成员 6 接入指南

## 1. 目标

成员 6 负责公共支撑与质量保障，包括日志、配置、异常封装和测试体系。

## 2. 需要提供的能力

```python
info(message: str) -> None
error(message: str) -> None
```

并逐步补充：

- 配置读取与保存
- 异常分类
- 测试工具
- 缺陷记录

## 3. 推荐文件位置

```text
ftp_client/utils/
├─ logger.py
├─ config.py
└─ exceptions.py

tests/
```

## 4. 工作节奏

成员 6 不应等待项目完成后才开始，而应：

1. 第一阶段先完成测试方案和日志模块
2. 第二阶段补充接口测试和配置模块
3. 第三阶段执行集成测试、异常测试和回归测试

## 5. 完成标准

1. 日志模块可被其他成员直接调用
2. 配置可独立维护
3. 主要模块均有测试记录
4. 缺陷能够被记录、跟踪和复测
