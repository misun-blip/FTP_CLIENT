# 成员 4 接入指南

## 1. 目标

成员 4 负责实现上传模块，使系统能够完成普通上传和上传断点续传。

## 2. 需要实现的接口

```python
upload(local_path: str, remote_path: str) -> TransferTask
resume_upload(local_path: str, remote_path: str) -> TransferTask
```

## 3. 推荐文件位置

```text
ftp_client/transfer/
├─ uploader.py
└─ upload_resume.py
```

## 4. 依赖

成员 4 依赖：

1. 成员 2 提供的数据连接与协议命令能力
2. 成员 1 提供的 `TransferTask`
3. 成员 6 提供的日志能力

## 5. 可先独立完成的部分

在真实协议层未完成前，可以先完成：

1. 本地文件分块读取逻辑
2. 上传任务类结构
3. 进度更新逻辑
4. 上传续传方案验证

## 6. 完成标准

1. 普通上传可用
2. 上传中断后可继续
3. 返回统一 `TransferTask`
4. 能通过上传功能测试
