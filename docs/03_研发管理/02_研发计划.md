# 研发计划

## 1. 阶段划分

### 阶段一：需求与设计

- 完成题目分析
- 明确功能范围
- 完成总体设计
- 完成模块拆分
- 明确接口

### 阶段二：基础功能开发

- 完成连接
- 完成登录
- 完成目录浏览
- 完成界面骨架

### 阶段三：核心功能开发

- 完成上传
- 完成下载
- 完成断点续传
- 完成进度展示

### 阶段四：联调与优化

- 模块集成
- 异常处理
- 界面优化
- 演示流程整理

### 阶段五：测试与交付

- 完成测试
- 整理实验报告
- 整理截图与流程图
- 完成最终提交

## 2. 里程碑

| 里程碑 | 目标 |
|---|---|
| M1 | 完成需求确认、总体设计、接口设计 |
| M2 | 完成连接、登录、目录浏览 |
| M3 | 完成上传、下载 |
| M4 | 完成断点续传与图形界面联调 |
| M5 | 完成测试、报告与最终版本 |
