# Mock 联调说明

## 1. 使用目的

在真实 FTP 协议实现尚未完成时，先使用 mock 服务验证：

1. 应用装配层是否可正常注入依赖
2. 公共模型是否可被各模块复用
3. GUI 或上层调用方是否已按接口基线对接

## 2. 当前提供的 mock

| mock | 用途 |
|---|---|
| `MockFTPClient` | 模拟连接、登录、目录查询 |
| `ConsoleLogger` | 在控制台输出日志 |

## 3. 使用方式

### 3.1 启动 mock 应用

```bash
python main.py --mock
```

### 3.2 运行 mock 联调演示

```bash
python scripts/demo_mock_integration.py
```

## 4. 适用场景

- 成员 5 在真实协议完成前开发 GUI
- 成员 1 验证应用装配流程
- 成员 6 编写集成测试
- 全组在首次联调前统一接口认知

## 5. 注意事项

1. mock 仅用于联调前验证，不代表真实协议行为
2. 真实模块接入后，应以真实实现替换 mock
3. 若接口基线变化，mock 也必须同步更新
