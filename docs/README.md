# FTP 客户端项目文档目录

```text
docs/
├─ 01_总体设计/
├─ 02_详细设计与接口/
├─ 03_研发管理/
└─ 04_测试与运维/
```

## 目录说明

| 文件夹 | 内容 |
|---|---|
| `01_总体设计` | 项目概述、需求范围、总体架构、功能模块 |
| `02_详细设计与接口` | 模块设计、接口定义、数据结构、流程设计 |
| `03_研发管理` | 角色分工、研发计划、协作规范、风险管理 |
| `04_测试与运维` | 测试方案、测试用例、运行维护、交付检查 |

其中：

- `03_研发管理/06_工作流与依赖关系.md` 用于说明 6 人协作时的先后顺序、依赖关系、可并行任务与阶段性推进方式
- `03_研发管理/15_协作开发流程规范.md` 用于统一项目从任务创建、开发、测试、联调到版本发布的完整协作流程
