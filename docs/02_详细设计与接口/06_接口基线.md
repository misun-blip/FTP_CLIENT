# 接口基线

## 1. 目的

接口基线用于在多人并行开发前，先统一各模块之间最小但稳定的调用约定，减少后续联调成本。

## 2. 基线版本

- 当前接口基线版本：`v0.1`
- 生效范围：基础连接、目录浏览、上传、下载、日志与 GUI 入口

## 3. 协议层接口

```python
connect(host: str, port: int, timeout: int = 10) -> None
login(username: str, password: str) -> bool
list_dir(path: str | None = None) -> list[RemoteFile]
close() -> None
```

## 4. 下载接口

```python
download(remote_path: str, local_path: str) -> TransferTask
resume_download(remote_path: str, local_path: str) -> TransferTask
```

## 5. 上传接口

```python
upload(local_path: str, remote_path: str) -> TransferTask
resume_upload(local_path: str, remote_path: str) -> TransferTask
```

## 6. 公共模型

### 6.1 `RemoteFile`

```python
RemoteFile(
    name: str,
    path: str,
    size: int,
    is_dir: bool,
    modified_time: str | None = None,
)
```

### 6.2 `TransferTask`

```python
TransferTask(
    direction: TransferDirection,
    local_path: str,
    remote_path: str,
    total_size: int,
    transferred_size: int = 0,
    status: TransferStatus = TransferStatus.PENDING,
)
```

## 7. 日志接口

```python
info(message: str) -> None
error(message: str) -> None
```

## 8. GUI 入口接口

```python
show() -> None
```

## 9. 变更规则

接口基线一旦进入开发阶段后，不应随意变化。若必须修改：

1. 先更新接口文档
2. 说明修改原因
3. 通知所有受影响成员
4. 同步修改调用方
5. 重新执行相关测试
