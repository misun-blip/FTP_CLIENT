# 模块详细设计

## 1. 连接模块

- 创建 socket
- 建立控制连接
- 设置超时时间
- 接收欢迎信息
- 关闭连接

## 2. 协议模块

- 封装常用命令
- 发送命令
- 接收响应
- 解析响应码
- 维护协议流程

支持命令：

- `USER`
- `PASS`
- `PWD`
- `CWD`
- `TYPE`
- `PASV`
- `LIST`
- `RETR`
- `STOR`
- `REST`
- `QUIT`

## 3. 文件浏览模块

- 获取远程目录列表
- 解析目录返回结果
- 转换为统一文件对象

## 4. 下载模块

- 建立数据连接
- 分块接收数据
- 写入本地文件
- 更新进度
- 支持续传
- 下载续传逻辑单独放置于 `download_resume.py`

## 5. 上传模块

- 建立数据连接
- 分块读取本地文件
- 发送文件数据
- 更新进度
- 支持续传
- 上传续传逻辑单独放置于 `upload_resume.py`

## 6. 任务管理模块

任务状态：

- `pending`
- `running`
- `paused`
- `completed`
- `failed`
- `cancelled`

## 7. 日志模块

- 记录命令
- 记录响应
- 记录异常
- 记录用户操作
