# 数据结构设计

## 1. 远程文件对象

```python
class RemoteFile:
    name: str
    path: str
    size: int
    is_dir: bool
    modified_time: str
```

## 2. 传输任务对象

```python
class TransferTask:
    task_id: str
    direction: str        # upload / download
    local_path: str
    remote_path: str
    total_size: int
    transferred_size: int
    status: str
```

## 3. FTP 响应对象

```python
class FTPResponse:
    code: int
    message: str
    raw: str
```
