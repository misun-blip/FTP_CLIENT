# 业务流程设计

## 1. 登录流程

```text
connect
  ↓
read welcome response
  ↓
USER username
  ↓
PASS password
  ↓
login success / failure
```

## 2. 下载流程

```text
获取文件大小
  ↓
建立数据连接
  ↓
RETR filename
  ↓
循环接收数据
  ↓
写入本地文件
  ↓
更新进度
  ↓
关闭数据连接
```

## 3. 下载续传流程

```text
读取本地已有大小
  ↓
REST offset
  ↓
建立数据连接
  ↓
RETR filename
  ↓
追加写入剩余内容
```

## 4. 上传流程

```text
读取本地文件
  ↓
建立数据连接
  ↓
STOR filename
  ↓
循环发送数据
  ↓
更新进度
  ↓
关闭数据连接
```
