# 接口定义

## 1. 连接接口

```python
connect(host: str, port: int, timeout: int = 10) -> None
close() -> None
```

## 2. 认证接口

```python
login(username: str, password: str) -> bool
```

## 3. 命令接口

```python
send_command(command: str) -> FTPResponse
```

## 4. 目录接口

```python
pwd() -> str
cwd(path: str) -> bool
list_dir(path: str | None = None) -> list[RemoteFile]
```

## 5. 下载接口

```python
download(remote_path: str, local_path: str) -> TransferTask
resume_download(remote_path: str, local_path: str) -> TransferTask
```

## 6. 上传接口

```python
upload(local_path: str, remote_path: str) -> TransferTask
resume_upload(local_path: str, remote_path: str) -> TransferTask
```

## 7. 日志接口

```python
log_info(message: str) -> None
log_error(message: str) -> None
log_protocol(command: str, response: str) -> None
```
